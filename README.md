# Ficha de Obra — Revestimentos Sil

Ficha de visita para orçamento de assentamento de pisos e revestimentos.
Preenchida no celular durante a visita; no final monta a mensagem pronta para o WhatsApp.

Abrir: https://brunopassos133.github.io/ficha-sil/

- Calcula a área a partir das medidas em metros
- Deduz o tipo de ambiente pela área (aberta / média / pequena / parede)
- Prévia do valor com a tabela de preços de mão de obra (SP capital, peças até 80x80)
- Botão para imprimir a ficha em branco em A4, para uso sem sinal

Os dados preenchidos ficam apenas no navegador de quem preenche.
